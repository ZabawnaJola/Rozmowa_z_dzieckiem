# Rozmowa_z_dzieckiem

Paczka projektu treningowego do pracy w Claude nad rozmową z dzieckiem (7-9 i 10-12), z oceną po każdej turze i raportami postępu.

## Start
1. Otwórz folder `PaczkadlaCLAUDE`.
2. W Claude Project ustaw jako główną instrukcję plik:
   - `PaczkadlaCLAUDE/INSTRUKCJE/PROJECT_INSTRUCTIONS.md`
3. Traktuj `PaczkadlaCLAUDE/BAZA_WIEDZY/` jako bazę wiedzy i szablony raportów.

## Struktura
- `PaczkadlaCLAUDE/INSTRUKCJE/` — instrukcje nadrzędne pracy modelu.
- `PaczkadlaCLAUDE/BAZA_WIEDZY/reporting/` — algorytmy, schematy i szablony raportów.
- `PaczkadlaCLAUDE/BAZA_WIEDZY/data_examples/` — przykładowe dane sesji i agregatów.
- `PaczkadlaCLAUDE/BAZA_WIEDZY/skills_design/` — pliki projektowe i metodyczne.

## Raportowanie
- Raport sesyjny: po każdej sesji.
- Raport skumulowany: co 5 sesji.
- Metryki: liczba rozmów, trend ocen, mocne strony, ryzyka, plan kolejnych ćwiczeń.
